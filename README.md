# 通知不漏办 · 校园通知转行动清单智能体

把零散的校园通知，一键转成可执行、可提醒、不遗漏的行动清单。

**线上地址**：https://zjmnb66611.github.io/notice-to-action/

## 核心能力

- **通知智能解析**：粘贴通知原文，自动提取标题、类别、截止时间、地点、紧急度，并拆解为可执行行动项
- **行动清单看板**：待办 / 进行中 / 已完成 / 已逾期四列流转，支持拖拽与一键完成
- **提醒预警**：临期（24 小时 / 3 天 / 7 天）与逾期自动标红预警
- **日历视图**：按截止日期上墙排布
- **搜索筛选**：关键词 + 类别 / 优先级 / 负责人 / 时间范围
- **数据看板**：完成率、分类分布、状态分布（纯 SVG 图表）
- **数据管理**：CSV 导出、JSON 备份导入、本地持久化

## 技术特点

- 单文件 HTML/CSS/JS，**零依赖、纯前端**
- 数据仅存于浏览器 localStorage，**不上传、不泄露**
- 通知解析为本地规则引擎，支持多种日期写法（`10月28日`、`本周五`、`三天内`、`今晚23:00` 等）

## 本地使用

直接用浏览器打开 `index.html` 即可，或：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 更新发布

本地修改 `notice-to-action.html` 后，复制为 `index.html` 提交推送即可：

```bash
git add index.html && git commit -m "update" && git push
```
