# 通知不漏办 · 校园日程工作台

把校园通知，整理成下一步要做的事。版本 2.0.0。

网站：https://zjmnb66611.github.io/notice-to-action/

## 怎样开始

1. 粘贴通知，或写一句口语，点击“整理待办”。
2. 核对每一项内容、日期和时刻，保留需要的项，再加入清单。
3. 日历看截止安排，今日清单和看板里编辑、推进、完成。打开待办可回看原文来源。
4. 需要换设备时下载 JSON 完整备份；需要系统日历时导出 ICS，并在日历应用中设置提醒。

右上角“使用说明”提供四步文字、常见问题与约 22 秒的中文字幕操作演示。视频为真实浏览器录制，含示例数据，无音轨，点击后才下载。

## 功能

- 苹果液态玻璃风格、真实校园窗边背景、白天/黑夜/跟随系统，背景和交互动画可关闭。
- 中文本地规则整理，支持口语、多项行动、相对日期、中文时刻、明确年月日；缺少或模糊日期不猜测。
- 可编辑预览、原文与来源行号、待定时间、负责人、分类、优先级、备注。
- 今日清单、四状态看板、周截止日历、通知库、真实数据统计；搜索和多条件筛选。
- 快速添加、编辑、完成、拖拽、误操作撤销、输入草稿、多页面写入冲突提示。
- CSV 清单导出、JSON 完整备份与合并导入、ICS 日历导出、损坏存储原始备份。
- 原版 nta_data_v1 数据兼容，严格导入校验、可靠日期恢复和安全输出。
- 手机布局、原生模态键盘交互、减少动态效果支持、短时加载反馈与低负载数码光迹。

“体验示例”只替换输入框，不会自动添加到清单；确认保存的内置示例可以在设置中一键移除。

## 边界

数据存在当前浏览器，不自动跨设备同步。当前版本不调用外部大模型或主动上传通知。规则整理可能漏识别或识别错误，保存前需核对。网页关闭后不会推送提醒。ICS 中的 15 分钟为截止事项显示占位，不代表活动持续时长。

旧版存储损坏时不会直接覆盖，可先下载原始存储；删除、合并和清空可撤销一次，后续修改或刷新后撤销记录不再保留。单文件备份最大 2MB，通知与待办总计最多 2000 条。JSON 文件包含原文，应妥善保管。详见 SECURITY.md。

## 本地与测试

直接打开 index.html，无需项目服务和安装运行依赖。

```powershell
node --test tests/core.test.cjs
node tools/build-offline.cjs /你的路径/通知不漏办-离线版.html
```

离线构建包含本地图片、Feather 图标、脚本及操作视频，并生成精确脚本 CSP 哈希。网站采用原生 HTML、CSS、JavaScript；核心逻辑独立于界面，便于验证与维护。

## 发布

GitHub Pages 使用仓库根目录的 index.html 和 assets/。修改、检查并确认暂存区后，按用户约定确认提交，再推送 main。不要再引用旧文档中并不存在的 notice-to-action.html。可选 vercel.json 仅用于 Vercel 托管；本项目主网址继续使用 GitHub Pages。

## 素材
