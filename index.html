日期没写清楚怎么办？

“尽快”“下周”等模糊说法保留为待确认。仅写日期时，按当天截止显示；没有年份时会提示核对。当前整理采用本地规则，可能漏识别或识别错误。





关闭网页后还会提醒吗？

页面内提醒在打开时更新，网页关闭后不会推送。需要系统提醒时，可导出 ICS 并在系统日历中设置提醒。





数据保存在哪里？

存在当前浏览器的本机存储，不上传通知，不自动跨设备同步；浏览器扩展、同源页面及设备环境仍会影响数据安全。请定期备份。





如何使用键盘？

输入框内 Ctrl / Command + Enter 整理；Tab 移动焦点，Enter 或空格操作按钮，Esc 关闭弹窗。任务状态也可在编辑窗口修改。
